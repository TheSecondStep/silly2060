# silly2060

口头叫傻妞。仓库叫 silly2060。

"傻"在剧里的外文是 silly。2060 是她开机自报的型号，华人牌 2060 款。拼在一起，读的人能对上魔幻手机。

## 宗旨

你人在手机上。你只做四件事。派活，点选，改口，叫停。

飞书、Discord、钉钉是你跟傻妞说话的地方。Cursor、Codex、Claude Code、DeepSeek Harness，以及后边接上的同类命令行，留在一台你离开后还开着的电脑上。也可以留在云端。这些命令行在这里叫做 Harness。

选哪个模型，钉哪组 Skill，在哪个仓库干，按你事先写好的路由走。

```mermaid
flowchart LR
  you["飞书、Discord、钉钉"] --> niu["傻妞"]
  niu --> route["路由。Harness、模型、Skill、仓库"]
  route --> hands["常开的电脑或云端 Harness"]
  hands --> brief["四行简报"]
  brief --> you
```

卡兹克的 [Agent Autoloop](https://github.com/KKKKhazix/agent-autoloop) 把调度定下来了。收事件。按规则派活。干完一轮就退出。等你拍板时不占进程，也不烧 token。拿不准才推卡片。

他那套是事情先发生，再来找你批。定时任务、GitHub Issue、报错，都算事情先发生。傻妞补的是反过来的那一头。人先在聊天里开口。你离开电脑和那些客户端之后，这句话还要能接住。

聊天就是客户端。你在飞书里说的一句，就是一条事件。钩子和回执先变成人话，再送回你正在看的那个聊天。

路由、你批准过的模式、简报要多长、哪台机器管哪个仓库，都记在傻妞这边。

## 第一版只打通一条

一台常开的机器。一个你每天真在用的 Harness。飞书一张卡片。一份路由文件。

你在手机上说一句。傻妞派出去。做完或者卡住，卡片回到飞书。你点一下，继续。

通道按这个顺序加。飞书，Discord，钉钉，企业微信。个人微信没有稳定的官方机器人接口，放在这些之后。

## 始终穿插的内容

以后每加一个通道、一张卡片、一条路由，都带上这些。开机那一句只在开机出现。

开机留一句 "华人牌 2060 款，傻妞为您服务。" 这是味道。产品是那张卡片和那份路由。

每张回到聊天里的简报都是四行。多出来的日志不进聊天。

1. 一句人话。在干什么，或者干完了什么。
2. 三行证据。改了哪些文件，或卡在哪。
3. 一个决定。继续，换一条路，停。选项来自她真实卡住的问题。
4. 一行路由。这次走了谁，哪个 Skill。想换，直接回一句。

卡片上你只能派活，点选，改口，叫停。

等拍板的时候，这一轮的进程已经退出，token 已经停掉。拿不准，才推这张卡片。

羁绊记在傻妞这边，不写进各个 Harness。记的是路由，你批准过的模式，简报要多长，哪台机器管哪个仓库。
